# SNI 导入集中保存，保留逐项结果

当前 SNI 批量导入逐条创建，并反复整理同一组已有规则和成员副本。按用户要求，借鉴 Nekopass 的整批提交与集中保存方式，在保存结束前统一整理受影响的配置，以减少重复工作；沿用本项目逐项成功失败的约定，能够归属到单条的错误只撤回该条，最终公共保存失败则不确认尚未完成的新增，避免留下半套配置。

该方案覆盖现有全部 SNI 导入，保存完成与入口实际生效分别确认。按用户最后明确的范围，本轮不引入批次持久化、结果找回、重启续做或新的输入容错规则。完整范围与验证要求已通过 to-spec 整理到[正式规格](../../.scratch/2026-10-15_服务端批量导入/spec.md)；本记录确认设计方向，不代表业务代码已经实现或验收通过。
