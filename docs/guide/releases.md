## 运行兼容

V3 的底层代码纳入本地构建，但网页与直接请求接口都不开放新建或切换 V3，现有 V1／V2 不自动转换。以后如开放，还须确认两端程序实际兼容，不能只看版本号相同。

此前同样显示 `3.3.0` 的旧 FXP 可能没有局部新增接口；新 Agent 会拒绝不支持的新增，保持现有业务。端口工具和诊断信息需要配套 Agent 的实际报告；未确认不能当作已经支持。

局部新增保留连接不等于升级过程不断线：更新二进制、首次启用控制入口、修改或删除已有监听，以及故障恢复仍可能替换进程。回执丢失时须核对真实状态，不能把它当成已撤回。升级前先[备份](./upgrade-backup.md)，之后验证真实 TCP／UDP 业务。

## 文档、检查和发布

本页说明本地源码的使用边界，不表示每一项已经完成实际业务验证或人工验收。实际检查、跳过和待验结果在本轮交付记录中分别列出；284 的历史验证也不能替代 285 的新验证。

文档站页面随源码构建；`build-info.json` 记录版本、来源提交、内容指纹及构建时间。看到文档更新不代表安装包已经发布，也不代表主机已经更新。正式版本历史见本项目[中文更新日志](https://github.com/owo10086/sni-panel/blob/main/CHANGELOG.md)和[英文更新日志](https://github.com/owo10086/sni-panel/blob/main/CHANGELOG.en.md)。

## 核对文档来自哪里

- **源码提交**表示保存了代码记录，不代表已构建或已发布安装包。
- **正式附件**以 [本项目 Releases](https://github.com/owo10086/sni-panel/releases) 为准。本轮本地检查不会覆盖已有附件、版本标签、镜像或 `latest`。
- **文档站**单独构建。站点显示的版本与已安装面板的版本可能不同，本地构建也不代表网站已经更新。

文档左上角显示构建时的面板版本。[构建信息](../build-info.json) 提供版本、代码记录、构建时间和本次内容的文件指纹。`sourceDirty: true` 表示含有尚未提交的文档或版本配置，不能只凭提交编号认为其中已包含这些改动；文件指纹可进一步核对内容。源码压缩包没有 Git 记录时，提交显示为 `local`，是否有未提交改动显示为未知。
