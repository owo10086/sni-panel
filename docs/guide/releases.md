前轮合入上游 `282 → 283` 的网页、面板服务端、Agent 和 FXP 改动，**保持上述版本号，不单独发布**。包括新主题与双语、规则搜索、主机删除预览、隧道新增保留连接、普通 TCP 每来源 IP 连接上限，以及套餐自定义说明。原生应用按长期约定排除，本轮不构建、更新或发布原生应用。

同样显示 `3.3.0` 的旧程序不一定具备新能力。普通端口限制按 Agent 实际报告的能力应用；不支持局部新增的旧 FXP 会拒绝这次新增并保留旧业务。SNI 不进入本轮新增的普通端口限制，继续使用既有的规则最大连接数。

新增保留连接不等于升级过程不断线：更新程序、首次启用控制入口、修改或删除已有监听，以及故障恢复仍可能替换进程。已经保存的规则若应用失败，会保留在面板中等待处理；回复丢失时需要核对实际状态，不能把它当成已撤回。升级前先 [备份](./upgrade-backup.md)，之后验证真实 TCP／UDP 业务。

已发布历史见 [中文更新日志](https://github.com/owo10086/sni-panel/blob/main/CHANGELOG.md) / [English changelog](https://github.com/owo10086/sni-panel/blob/main/CHANGELOG.en.md)。本轮未发布改动及实际验证记录见仓库的 [283 合并目录](https://github.com/owo10086/sni-panel/tree/main/.scratch/2026-10-17_合并上游v2.3.283)，本地记录尚未推送时，该链接可能暂时不可访问。完成本轮后再单独讨论 `284`。

## 核对文档来自哪里

- **源码提交**表示保存了代码记录，不代表已构建或已发布安装包。
- **正式附件**以 [本项目 Releases](https://github.com/owo10086/sni-panel/releases) 为准。本轮本地检查不会覆盖已有附件、版本标签、镜像或 `latest`。
- **文档站**单独构建。站点显示的版本与已安装面板的版本可能不同，本地构建也不代表网站已经更新。

文档左上角显示构建时的面板版本。[构建信息](../build-info.json) 提供版本、代码记录、构建时间和本次内容的文件指纹。`sourceDirty: true` 表示含有尚未提交的文档或版本配置，不能只凭提交编号认为其中已包含这些改动；文件指纹可进一步核对内容。源码压缩包没有 Git 记录时，提交显示为 `local`，是否有未提交改动显示为未知。

## 文档看起来没有更新时

1. 查看 [本项目 Docs 流程](https://github.com/owo10086/sni-panel/actions/workflows/docs.yml)，确认构建和部署是否实际完成。
2. 排队或构建失败时，网站仍可能显示上一次成功部署的内容；刷新浏览器不能代替部署。
3. 部署后核对构建信息；自定义域名、反向代理或 CDN 还需核对缓存。

维护者另行决定发布后，可运行文档部署流程。这里说明核对方式，本轮只构建和检查本地文档。
