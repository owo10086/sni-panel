# 02 — 检查入口 Agent 的分流器版本

**What to build:** 所有可能创建、修改或恢复入口分流器的规则操作均检查相关入口 Agent 是否达到分流器最低版本，并与出口分流器使用同一个最低版本定义。版本不足时给出具体主机和版本信息，避免保存一条无法运行的规则。

**Blocked by:** None — 09 中入口版本异常所需的服务器端撤除行为已完成；其余场景和部署验收另行跟进

**Status:** done

- [x] 创建转发链 SNI 分流规则时检查全部相关入口主机，任一主机版本不足即拒绝保存
- [x] 修改规则、启用此前停用的规则及批量导入时执行相同检查
- [x] 表单实时预检与保存操作使用相同的入口主机范围和最低版本定义，并返回一致的判断
- [x] 入口组中的每台启用主机都参与检查，不以单台代表主机代替整个入口组
- [x] Agent 版本未上报、版本格式无法识别或低于最低版本时均视为不满足要求
- [x] 错误信息包含入口主机名称、主机标识、当前版本状态和所需最低版本
- [x] 已存在规则遇到不满足版本要求的入口主机时明确显示错误并停止运行，不回退到 gost 或 nginx
- [x] 出口 Agent 的既有版本检查和最低版本保持不变
- [x] 规则接口配合临时数据库的测试覆盖创建、修改、启用、批量导入和实时预检
