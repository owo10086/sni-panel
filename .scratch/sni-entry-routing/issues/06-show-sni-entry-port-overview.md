# 06 — 提供只读的 SNI 入口全貌页面

**What to build:** 管理员可以按入口主机和入口端口查看全部转发链 SNI 分流规则，包括域名、所属转发链、规则保存的目标地址和端口、入口组差异及 Agent 版本状态。该页面只展示派生信息，不形成第二个配置入口。

**Blocked by:** 02 — 检查入口 Agent 的分流器版本；03 — 允许多条转发链共用一个入口端口

**Status:** resolved

- [x] 查询结果按入口主机和入口端口分组，并覆盖直接入口主机和入口组成员
- [x] 每条路由显示规范化域名、规则名称、启用状态、所属转发链及规则保存的目标地址和端口
- [x] 页面清楚区分目标地址和已登记主机实体，不把任意目标地址错误标记为主机资源
- [x] 共享同一批规则的入口组成员在相同入口端口上比较启用域名集合，集合不同时返回差异标记和每台主机缺少的域名
- [x] 域名集合差异只作提示，不阻止合法的单入口和多入口混合配置
- [x] 每台入口主机显示 Agent 当前版本、最低版本及是否满足要求
- [x] 页面只提供查看和导航能力，不提供创建、修改或删除入口配置的操作
- [x] 只有管理员能够访问查询和页面
- [x] 规则接口配合临时数据库的测试覆盖跨转发链路由、入口组差异、停用规则和 Agent 版本状态

## Comments

2026-09-17 实施摘要：核对管理员只读入口全貌页面与查询，按主机和端口展示规范化域名、规则、转发链、目标地址及版本状态。规则接口测试验证跨链路由、入口组缺少域名提示、停用规则和管理员权限，并补充无法识别版本的检查。查询与升级区域共用最低版本及共享版本判断，相关测试和类型检查通过。
