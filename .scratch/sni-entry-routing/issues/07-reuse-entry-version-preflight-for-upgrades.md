# 07 — 在面板升级区域复用入口版本预检

**What to build:** 面板升级确认区域在执行升级操作前复用 SNI 入口全貌查询，提前列出需要升级 Agent 的入口主机，并提供查看完整入口信息的入口。

**Blocked by:** 04 — 让共享入口分流表更新只影响变更规则；06 — 提供只读的 SNI 入口全貌页面

**Status:** resolved

- [x] 升级区域复用入口全貌查询及其最低版本定义，不新增另一套入口主机遍历和版本判断
- [x] 所有相关入口 Agent 满足要求时显示检查通过状态和最低版本
- [x] 版本不足、版本未上报或版本无法识别时，列出入口主机名称、当前版本状态和最低版本
- [x] 查询进行中显示明确的加载状态，查询失败时显示错误原因
- [x] 没有转发链 SNI 分流规则时不显示无意义的版本警告
- [x] 版本警告提供进入只读 SNI 入口全貌页面的导航
- [x] 升级提示明确已有入口监听会统一切换为入口分流器，切换时既有连接发生一次中断
- [x] 升级提示明确完成切换后的新增、修改和删除继续使用分流表热更新
