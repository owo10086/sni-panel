# 05 — 以入口和出口共同确认规则运行状态

**What to build:** 转发链 SNI 分流规则只有在所有相关入口分流器和出口分流器都确认域名已经进入当前有效配置后才显示为运行中。规则列表分别呈现入口和出口信息，使配置未生效的位置可以被明确识别。

**Blocked by:** 03 — 允许多条转发链共用一个入口端口

**Status:** resolved

- [x] 仅出口确认域名、仅入口确认域名或入口组中只有部分主机确认域名时，规则均不显示为运行中
- [x] 所有相关入口分流器和出口分流器均确认域名后，启用中的规则显示为运行中
- [x] 入口 Agent 版本不足、链路资源停用、规则停用或规则等待删除时，运行状态保持为未运行
- [x] 规则查询为每台入口主机和出口主机分别返回主机、端口、是否观测到、域名是否生效、当前配置版本、未匹配连接数、最近配置错误和观测时间
- [x] 规则列表分别显示入口与出口的生效状态、配置版本、未匹配连接数和最近配置错误
- [x] 入口未匹配计数旁说明域名拼写、DNS 指向或端口扫描等含义，出口未匹配计数旁说明入口与出口配置可能尚未同步
- [x] 入口组场景保留每台入口主机的明细，不使用单个聚合布尔值掩盖部分入口异常
- [x] 中转成员的运行状态上报不会覆盖同端口入口分流器或出口分流器的观测信息
- [x] 端口占用警告及其它旧运行状态使用位置不再把入口分流器自身监听误认为规则异常
- [x] 隧道和端口转发承载的 SNI 分流规则继续沿用既有出口生效语义
- [x] 心跳与规则接口测试覆盖入口未确认、部分入口确认、出口未确认、全部确认和配置错误场景
