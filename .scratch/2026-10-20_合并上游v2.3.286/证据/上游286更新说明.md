# Changelog

[简体中文](CHANGELOG.md) | [English](CHANGELOG.en.md)

## [2.3.286] - 2026-10-19

- Android / iOS 桌面图标跟随预设主题和深浅模式切换，统一默认 Logo。
- 修复浏览器标签页图标与面板 Logo 不一致，跟随主题配色及自定义 Logo 更新。
- 人机验证设置改为左右两列，支持管理员切换点击验证或混淆图片验证码，服务端严格校验所选方式。
- 首屏仅加载当前页面，菜单意图预取；切页保留导航与升级状态，不使用全屏加载遮罩。
- 账单流水支持带样式的 Excel 导出：管理员可导出全部或指定用户，普通用户仅可导出自己的全部记录。
- 优化主机编辑布局和 DDNS 紧凑选择，服务弹窗顶部可切换探测模式，精简国内检测说明。
- 主机支持检测多个公网 IPv4/IPv6，分别选择主 IP；DDNS 支持 A + AAAA 双栈及仅主 IP/全部 IP 同步。
- 主机服务新增国内健康检测：连续异常后自动通知、通过对应 Agent 调用商家内网 HTTP/HTTPS 换 IP 接口，无需回复确认；支持冷却、次数限制、防重复执行和地址同步。
- AI 新增精确用户统计和实际流量排行，支持对象、时段、方向与权限范围筛选。
- AI 配置新增仅管理员可用的外部只读 MCP 接口，支持独立限时令牌、撤销、权限校验与限流。
- 网络测试增加 Ping 摘要、路由逐跳展示及主机/规则配置体检。
- 运维看板新增全局资源状态、安全配置检查及默认关闭的持续资源告警，记录触发与恢复并支持通知。
- FXP 增加业务数据发送前的建连/hello 失败节点切换，修正同端口节点识别；不含已建立连接的跨中转续传。
- 订阅套餐和按量计费资源支持卡片、列表拖动排序，保存后同步商店展示顺序。
- 规则列表默认展示“我的规则”，不再恢复上次的用户筛选。
- 修复选择规则分类后无法拖动排序的问题。
- 优化运维地图悬浮详情的位置，自动避让当前省份。
- 优化首次和后续打开首页的速度，统计与图表先展示缓存、后台独立更新。
- 更新登录与注册页面，优化切换动效和语言选择样式，适配手机、中英文和深浅主题。
- 修复首页导航栏重复显示 Logo 的问题。
- 优化旧数据库升级和历史清理，避免积压清理阻塞启动，明确提示迁移失败原因。
- 数据库异常提示更明确，补充来源授权、账号权限和升级失败的排查建议。
- 修复运维看板规则排行只显示数字的问题，优先展示规则名称。
- 调整开关阴影，改善圆点视觉偏移。
- Agent 安装和脚本升级自动检查来源流量采集依赖、开启并验证连接计数，失败时明确告警。
- 移除刷新时的全屏面板状态检查提示，改为后台检查；保留数据库故障提示与恢复检测，减少启动重复请求。
- 修复多入口隧道延迟结果不刷新、失败入口误显示“等待探测”的问题，补充分段诊断提示。

- 版本：面板 `2.3.286`，Android / iOS `2.4.4`，Agent `2.2.199`，ForwardX FXP runtime `2.2.120`。多 IP / 自动换 IP 需升级 Agent，桌面图标同步需更新 App。
