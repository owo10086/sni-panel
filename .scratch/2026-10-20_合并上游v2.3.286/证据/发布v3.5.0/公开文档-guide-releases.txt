<a class="header-anchor" href="#版本与文档更新" aria-label="Permalink to &quot;版本与文档更新&quot;">​</a></h1><h2 id="当前版本-3-5-0" tabindex="-1">当前版本 3.5.0 <a class="header-anchor" href="#当前版本-3-5-0" aria-label="Permalink to &quot;当前版本 3.5.0&quot;">​</a></h2><table tabindex="0"><thead><tr><th>组件</th><th>本项目对外版本</th></tr></thead><tbody><tr><td>面板</td><td>3.5.0</td></tr><tr><td>Agent</td><td>3.5.0</td></tr><tr><td>FXP 运行时</td><td>3.5.0</td></tr></tbody></table><p>3.5.0 整合上游 286 的网页、服务端和运行程序改进，新增主机多公网地址与主地址选择、可选独立健康及自动换 IP、管理员外部只读接入、可选图片验证码、持续资源告警和完整账单 Excel 导出，并改进网页加载、网络诊断、数据库升级与后台清理。</p><p><strong>本版需要一起升级面板及配套 Agent／FXP。</strong> 旧程序不会因面板更新自动获得多地址上报、换 IP 任务或新的建连处理。先<a href="./upgrade-backup">备份</a>，正式资产以<a href="https://github.com/owo10086/sni-panel/releases/tag/v3.5.0" target="_blank" rel="noreferrer">本项目 3.5.0 发布页</a>为准。</p><p>自动换 IP 和持续资源告警默认关闭，外部只读接入凭证由管理员主动创建。旧单 IP 解析保留旧更新方式；完整名单模式由管理员主动启用，需使用专用域名，切回主 IP 仍清理多余记录。详见<a href="./hosts">主机</a>、<a href="./ddns">DDNS</a>、<a href="./observability-mcp">外部只读接入</a>、<a href="./operations">运维</a>和<a href="./billing">账单</a>。</p><p>本地 SNI 与主机型主备组判断继续保留：目标检测异常不单独卡住入口；入口在线、应运行规则、当前完整 SNI 配置确认、已开启的入口检测及观察等待仍须满足。自动检查与独立审查完成，真实业务和用户人工验收另行记录；发版不表示主机已经升级。</p><h2 id="_3-4-1-的面板修复" tabindex="-1">3.4.1 的面板修复 <a class="header-anchor" href="#_3-4-1-的面板修复" aria-label="Permalink to &quot;3.4.1 的面板修复&quot;">​</a></h2><table tabindex="0"><thead><tr><th>组件</th><th>本项目对外版本</th></tr></thead><tbody><tr><td>面板</td><td>3.4.1</td></tr><tr><td>Agent</td><td>3.4.0</td></tr><tr><td>FXP 运行时</td><td>3.4.0</td></tr></tbody></table><p>3.4.1 修正主机型主备转发组的入口选择：普通业务目标失败、缺失或过期不再单独拖住整组解析，入口自身的在线、规则运行、已开启健康检查和观察等待仍须满足；普通规则的故障等待可跨面板重启接续，规则移组再移回时也能识别当前有效副本。<strong>从 3.4.0 升级只需更新面板，Agent／FXP 保持 3.4.0。</strong> 正式资产以<a href="https://github.com/owo10086/sni-panel/releases/tag/v3.4.1" target="_blank" rel="noreferrer">本项目 3.4.1 发布页</a>为准；源码或文档更新不代表主机已经升级。</p><p>调整限于主机型主备组，不扩展到多入口组、端口资源、出口组、转发链或隧道型主备组。目标服务自身仍须单独处理，逐条业务失败继续展示。</p><h2 id="_3-4-0-的运行程序升级边界" tabindex="-1">3.4.0 的运行程序升级边界 <a class="header-anchor" href="#_3-4-0-的运行程序升级边界" aria-label="Permalink to &quot;3.4.0 的运行程序升级边界&quot;">​</a></h2><p>3.4.0 汇总上游 283—285 的网页、服务端、Agent 和 FXP 改进，并补充 SNI 端口资源通过入口组直接连接落地的方式。从更早版本升级时，仍须按 3.4.0 的说明更新配套 Agent／FXP；面板补丁版本不让旧二进制自动具备这些能力。</p><p>相关使用说明：</p><ul><li><a href="./port-entry-groups">多入口端口转发</a>、<a href="./sni-routing#端口资源通过入口组直接分流">SNI 多入口分流</a>：入口并行服务、每台入口的当前配置确认和解析资格。</li><li><a href="./nyanpass-import">ny 实验导入</a>：先预览、停用导入、逐条保留失败结果。</li><li><a href="./operations">运维看板</a>：实际流量、来源采样、离线定位、按币种核对财务和自动刷新。</li><li><a href="./billing">账单与兑换</a>、<a href="./payments">支付对接</a>：服务端分页、完整支付核验、主动查单和七天迟到付款处理。</li><li><a href="./hosts#上下线通知">主机通知</a>、<a href="./affiliates">推广返佣</a>、<a href="./support-tickets">工单支持</a>：业务开关、菜单展示和个人通知分别管理。</li></ul><p>本轮保留原生应用排除约定，不新增 Android、iOS／iPadOS 的工程、安装、更新或发布说明。之前的网页主题、双语、主机安全删除、代理管理、探测计数及账目保护继续保留。</p><h2 id="运行兼容" tabindex="-1">运行兼容 <a class="header-anchor" href="#运行兼容" aria-label="Permalink to &quot;运行兼容&quot;">​</a></h2><p>V3 的底层代码纳入本地构建，但网页与直接请求接口都不开放新建或切换 V3，现有 V1／V2 不自动转换。以后如开放，还须确认两端程序实际兼容，不能只看版本号相同。</p><p>此前同样显示 <code>3.3.0</code> 的旧 FXP 可能没有局部新增接口；新 Agent 会拒绝不支持的新增，保持现有业务。端口工具和诊断信息需要配套 Agent 的实际报告；未确认不能当作已经支持。</p><p>局部新增保留连接不等于升级过程不断线：更新二进制、首次启用控制入口、修改或删除已有监听，以及故障恢复仍可能替换进程。回执丢失时须核对真实状态，不能把它当成已撤回。升级前先<a href="./upgrade-backup">备份</a>，之后验证真实 TCP／UDP 业务。</p><h2 id="文档、检查和发布" tabindex="-1">文档、检查和发布 <a class="header-anchor" href="#文档、检查和发布" aria-label="Permalink to 记录版本、来源提交、内容指纹及构建时间。看到文档更新不代表安装包已经发布，也不代表主机已经更新。正式版本历史见本项目<a href="https://github.com/owo10086/sni-panel/blob/main/CHANGELOG.md" target="_blank" rel="noreferrer">中文更新日志</a>和<a href="https://github.com/owo10086/sni-panel/blob/main/CHANGELOG.en.md" target="_blank" rel="noreferrer">英文更新日志</a>。</p><h2 id="核对文档来自哪里" tabindex="-1">核对文档来自哪里 <a class="header-anchor" href="#核对文档来自哪里" aria-label="Permalink to &quot;核对文档来自哪里&quot;">​</a></h2><ul><li><strong>源码提交</strong>表示保存了代码记录，不代表已构建或已发布安装包。</li><li><strong>正式附件</strong>以 <a href="https://github.com/owo10086/sni-panel/releases" target="_blank" rel="noreferrer">本项目 Releases</a> 为准。本轮本地检查不会覆盖已有附件、版本标签、镜像或 <code>latest</code>。</li><li><strong>文档站</strong>单独构建。站点显示的版本与已安装面板的版本可能不同，本地构建也不代表网站已经更新。</li></ul><p>文档左上角显示构建时的面板版本。<a href="../build-info.json">构建信息</a> 提供版本、代码记录、构建时间和本次内容的文件指纹。<code>sourceDirty: true</code> 表示含有尚未提交的文档或版本配置，不能只凭提交编号认为其中已包含这些改动；文件指纹可进一步核对内容。源码压缩包没有 Git 记录时，提交显示为 <code>local</code>，是否有未提交改动显示为未知。</p><h2 id="文档看起来没有更新时" tabindex="-1">文档看起来没有更新时 <a class="header-anchor"
