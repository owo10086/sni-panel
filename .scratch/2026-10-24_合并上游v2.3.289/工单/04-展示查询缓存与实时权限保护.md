# 04：展示查询缓存与实时权限保护

Status: completed

**交付行为：** 用户更快读取列表和展示摘要，并发查询得到合并处理；账号数据保持隔离，权限撤销立即生效，交易、库存与入口决策继续使用当前状态。

**Blocked by:** 无（可独立开始）。

**规格对应：** [唯一规格](../spec.md)；用户故事 20、21、31–33、35；实施决定 10–13、18、19、21。

**执行边界：** 用户已通过 `$implement` 明确授权本地实施、验证、审查及当前分支中文提交。按固定上游 v2.3.289 兼容适配，保留既有工作区内容，不创建工作树；不推送、不打标签、不发布或部署。

## 验收标准

- [x] 固定上游涉及的展示查询采用短缓存、并发请求合并和有界排队，异常后能正常恢复，排队和并发刷新不会无限增长。
- [x] 一般展示缓存新鲜期为 2 秒，之后额外 8 秒可返回旧展示并后台刷新；规则和主机分页列表仅使用 2 秒新鲜缓存，不返回该旧值窗口。
- [x] 缓存和合并请求按有效角色、账号及完整查询条件隔离，分页、筛选、排序等变化不串用结果。
- [x] 读取前后的现有授权检查保留；角色、账号权限或资源权限撤销后立即拒绝访问，不能以缓存命中继续读取已无权访问的数据。
- [x] 既有写入在适当的前后边界失效，成功、失败或部分变更均按实际影响处理；本地后台结算、规则收尾、权限变更和数据库切换不会继续复用不适用的数据。
- [x] 认证、权限证明、余额、支付兑换、库存执行及流量限额继续读取当前有效状态，不把展示结果当作授权或扣费依据。
- [x] SNI 完整配置确认、入口健康和 DDNS 不读取展示缓存作决策，遵守 ADR-0006、ADR-0007、ADR-0008 的范围与观察条件。
- [x] 缓存不以历史绿色状态覆盖当前明确运行错误、有效占用诊断或当前配置；规则异常展示保留 ADR-0004 的优先级。
- [x] 本单覆盖既有写入的失效链路；第 02、03 单各自负责新增库存业务写入的接入，第 08 单核对组合行为，不为尚未实施的新功能虚报验证通过。

## 验证入口

沿用现有会话、安全并发、后台摘要、授权查询、数据库切换与计费收尾验证，使用带不同账号和角色的真实查询入口。断言返回内容、权限拒绝、时间窗口和写后可见性，并以可控并发验证请求合并、排队上限和失败后的恢复。

## 实施与验证结果（2026-10-24）

- `390c586`、`9337108` 引入有界展示缓存、同键请求合并、共享加载池、排队上限及写入前后失效，保留列表 2 秒与一般展示 2 秒＋8 秒的区别；失效前的在途加载不能回填旧值。
- 缓存按账号、角色和完整查询条件隔离。`hosts.summary` 的实时 ACL 查询位于缓存外，授权范围进入缓存键；后台直接撤权后不会返回之前有权查看的主机数据。
- 规则仓库提交后按 owner／管理员／指标范围失效，数据库关闭时清空；支付、库存、认证、余额、入口与 DDNS 决策不使用展示缓存。
- 查询缓存与真实路由回归通过。路由回归 11 项覆盖跨账号、写后读取、后台写入、直接撤权、数据库关闭和真实 Agent HTTP 上报。
- 规格审查发现 Agent 运行状态与后台批量停用可能沿用旧规则列表，已在 `2678588` 修复：单条、批量运行／停止、toggle、协议或端口策略停用及 volatile 状态更新均按实际变化失效；相同状态重复上报继续复用缓存。新增回归证明失败上报后列表立即为 `isRunning=false`，批量恢复与停止也立即可见。
- 双轴审查复核后无未解决发现；有效占用诊断和当前绑定失败的优先级未改变。
