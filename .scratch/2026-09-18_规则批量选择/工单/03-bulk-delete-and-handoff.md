# 03 — 删除所选与跳转大弹窗

Status: resolved

**What to build:** 操作栏再加两个动作。「删除所选」复用 `rules.deleteBatch` 和现有确认弹窗一次删掉选中的规则。「更多批量操作」带着当前选择打开大弹窗，用于内联覆盖不到的批量复制、导出、导入和跨页选择。

规格见 `../spec.md`。

**Blocked by:** 01 — 规则列表行内多选；02 — 选中操作栏与批量编辑对话框（`RuleBulkActionBar.tsx` 由 02 创建，本票只往里加按钮）

## 验收标准

### 删除所选
- [x] 操作栏含「删除所选」，视觉上是破坏性动作
- [x] 点击先走现有 `confirmDialog`，描述写明「确认删除选中的 N 条转发规则？」
- [x] 复用 `rules.deleteBatch`，按现有 500 一批的分块方式提交
- [x] 删除成功的规则从选择里移除，删除失败的保留勾选
- [x] 全部成功：toast 报删除条数；部分失败：toast 报「成功 N 条，失败 M 条：<第一条错误>」
- [x] 完成后刷新规则列表、汇总、流量等相关查询，与大弹窗批量删除后的失效范围一致
- [x] 删除后若当前页已空且不是第一页，分页行为与单条删除后一致

### 更多批量操作
- [x] 操作栏含「更多批量操作」
- [x] 点击带着当前选中的规则 ID 打开大弹窗，弹窗左侧清单里这些规则显示为已勾选
- [x] 同时把弹窗内部的类别筛选与搜索框重置为默认，确保预选的规则真的可见
- [x] 落在大弹窗现有的默认页签（批量复制），不改它的默认页签逻辑
- [x] 关闭大弹窗后返回列表，行内选择状态不被弹窗内的勾选改动污染

### 不回归
- [x] 工具栏原有的「批量管理」按钮行为与改动前一致
- [x] 单条规则的删除按钮与确认流程与改动前一致
