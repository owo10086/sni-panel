# 02 — 按用户管理规则并统一 SNI 权限与额度

Status: ready-for-agent

**Blocked by:** 01

**目标：** 完成上游按所选用户新建、复制、导入、重置统计及有效端口策略，并按已确认的 Q3 A、Q4 A 与本地 SNI 和批量操作兼容。

规格见[所选用户、SNI 权限与规则操作](../spec.md)。主要涉及 `client/src/pages/Rules.tsx`、`server/routers/rules.crud.ts`、`rules.ports.ts`、`rules.traffic.ts`、规则操作归属模块、额度预留与权限仓储。

## 实施范围

- [ ] 区分实际操作人与规则归属用户：管理员权限按登录人判断，资源、套餐、余额、端口范围与额度按归属用户校验，避免整体替换 `ctx.user` 后误用身份。
- [ ] 管理员新建、复制、导入的规则归当前选定用户；“所有用户”下默认归管理员本人。编辑已有规则不改变归属，普通用户不能借请求参数替其他用户操作。
- [ ] 管理员可为普通用户配置 SNI；普通用户只能查看、启停、删除自己的 SNI 根规则或模板，创建、复制、导入与任何配置修改仍要求管理员。
- [ ] 统一直接隧道与转发组模板的启用判断；重新启用检查当前使用资格、有效端口及额度，停用或删除不因套餐过期、余额不足、授权撤销而被拦截。
- [ ] 保持系统子规则由根规则或模板管理。前后端、单条与现有批量入口执行相同权限；不能把 SNI 一律设成不可勾选而阻断已允许的批量删除。
- [ ] 按实际新增入口端口进行额度预留。同一用户复用已有 SNI 端口不重复占端口额度，新增规则仍占规则额度；并发创建仍执行现有额度保护。
- [ ] 重新启用已有规则不把已计入额度的规则和端口再计一次，恰好达到上限不应错误阻止恢复。系统子规则继续不重复计数。
- [ ] 保留行内选择、全选、批量修改、删除、复制和逐项结果反馈；混合选择中的权限失败不能绕过后端检查，也不能影响正确报告已完成项。
- [ ] “重置全部统计”覆盖当前选定用户范围的所有分页，忽略搜索、链路、类别和勾选状态，确认提示说明范围；不修改账户套餐用量、余额或计费记录。
- [ ] 端口提示采用服务端有效策略，与提交校验一致；保留 SNI 强制 TCP、同端口复用与现有占用提示契约，不恢复已撤除的创建时主机监听占用拦截。

## 验收条件

- 覆盖管理员选择自己、指定普通用户、所有用户时的新建、复制、导入，及普通用户伪造归属参数和越权操作。
- 覆盖直接隧道、转发组模板的普通归属用户启停、删除；验证普通用户修改非 SNI 字段也不能修改 SNI 规则配置。
- 覆盖权限或套餐失效后的重新启用拒绝、停用和删除成功，及额度满额恢复、共用端口新建、并发额度保护。
- 覆盖单条和现有批量入口、普通与 SNI 混合选择、派生子规则保护。
- 跨分页并叠加搜索和链路筛选，确认统计重置仍严格按用户范围执行，账户套餐用量不变。
- 在 `合并记录.md` 记录行为验证依据；需要的回归用例优先复用规则路由、额度预留、端口策略与批量操作现有测试入口。
