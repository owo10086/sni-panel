# 02: 有界请求接收与异常容量释放

**What to build:** 面板在接收与解析请求时限制资源占用，异常请求获得明确反馈，合法上传和小型 Agent 请求保持可用。

**Blocked by:** None（实施授权已获得）。

**Status:** completed（本地实施与隔离验收完成，未发布）

**依据：** [本轮规格](../spec.md)，用户故事 58；实施决定 29。

**实施边界：** 用户已通过 `$implement 开始实施` 授权本地代码实施、隔离验证与当前分支中文提交。按本轮固定累计范围兼容，遵守长期约定与排除项，保护实际基线及独立任务成果；不创建工作树、不操作生产、不推送或发布。

- [x] JSON／表单在完整缓冲与解析前受到大小、总并发、单 IP 容量、大请求预算与读取超时约束；压缩及分块传输不能绕过限制。
- [x] 超大、繁忙、超时和无效请求分别返回 413、429、408 和 400，繁忙响应包含重试提示，不扩展新的通用抗攻击系统。
- [x] 断连、中断、解析失败及响应结束均正确释放容量；大型已解析请求在响应结束前继续占用相应预算。
- [x] 合法插件归档上传、小型 Agent 注册／心跳和现有业务请求兼容，不将原生客户端纳入交付。
- [x] 沿用真实 HTTP 接收边界，覆盖突发并发、压缩、分块、慢读、异常断开及之后的容量恢复；验证反馈状态与合法请求结果，不只检查内部计数。
