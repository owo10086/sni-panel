# 16: 管理员重置端口转发资源展示流量

**What to build:** 管理员可以重置指定端口转发资源对所有用户显示的北京时间当日和累计流量，实际用量、账务及其他资源保持正确。

**Blocked by:** None（实施授权已获得）。

**Status:** completed（本地实施与隔离验收完成，未发布）

**依据：** [本轮规格](../spec.md)，用户故事 30；实施决定 15、19。

**实施边界：** 用户已通过 `$implement 开始实施` 授权本地代码实施、隔离验证与当前分支中文提交。按本轮固定累计范围兼容，遵守长期约定与排除项，保护实际基线及独立任务成果；不创建工作树、不操作生产、不推送或发布。

- [x] 从管理界面确认到服务端授权与展示刷新完整落地，仅管理员操作指定端口转发资源；普通用户、非端口资源、缺失或无效标识拒绝。
- [x] 重置只改变展示基线，不改变实际计数、规则额度、套餐用量、计费记录、历史或运行状态，关联入口组与其他端口资源不变；空资源不误重置全部规则。
- [x] 所有用户视图失效旧缓存并显示同一新基线；保留原有同步操作，重置后新增流量正常累加。
- [x] 重复重置替换基线、不叠加扣减；前一日基线不扣减次日流量；重置原子回滚、资源删除清理基线正确。
- [x] 基线持久化，重启后保留，SQLite、MySQL、PostgreSQL 支持新建和升级，已有展示、账务和独立任务数据不丢失。
- [x] 通过不同账号、真实测试数据库、可控北京时间和网页验证确认、权限、重复重置、跨日、重启、并发失败、缓存及删除，比较账务和其他资源的前后结果。
