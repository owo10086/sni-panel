# 07: 扩展端口导入与 TXT 导出重导入

**What to build:** 用户可导入端口范围、端口列表或逐行监听端口与目标，导出的 TXT 可直接重导入并保留监听端口。

**Blocked by:** None（实施授权已获得）。

**Status:** completed（本地实施与隔离验收完成，未发布）

**依据：** [本轮规格](../spec.md)，用户故事 15、16、17、18、23、43；实施决定 6、7。

**实施边界：** 用户已通过 `$implement 开始实施` 授权本地代码实施、隔离验证与当前分支中文提交。按本轮固定累计范围兼容，遵守长期约定与排除项，保护实际基线及独立任务成果；不创建工作树、不操作生产、不推送或发布。

- [x] 纳入端口范围、列表及逐行监听端口／目标输入，旧格式继续兼容，预览与实际保存解释一致；TXT 往返保留监听端口和逐项失败信息。
- [x] 继续将普通、SNI 或混合内容导入所选同一个已有链路资源，保留 SNI 分类、域名校验、预览与使用权限，不混同跨目标批量复制。
- [x] 沿用现有集中保存入口，每请求最多 500 条，逐项保存点、原始行号、混合输入的额度／端口竞争顺序和集中配置整理保持不变，不逐条普通创建或静默拆批。
- [x] 单条可归属错误隔离回撤，公共保存失败不报告成功；保存完成与入口实际生效分别展示。
- [x] 验证合法及非法端口、边界数量、旧输入、TXT 往返、普通／SNI／混合、额度和共享监听，通过实际保存结果及运行期望状态验收。
- [x] 本单完成后仍能通过既有导入入口独立使用；后台队列适配由 08 接续，不留下只可解析却不能保存的中间状态。
