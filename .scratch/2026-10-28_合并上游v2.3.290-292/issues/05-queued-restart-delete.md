# 05: 后台批量重启与删除的运行及账务收尾

**What to build:** 用户在同一后台任务体验中重启或删除选定规则，暂停状态、统计、资源归属和删除后的费用收尾保持正确。

**Blocked by:** 04：后台批量启停与任务跟踪闭环。

**Status:** completed（本地实施与隔离验收完成，未发布）

**依据：** [本轮规格](../spec.md)，用户故事 9、10、11、21、22、23、43、44；实施决定 6、8、9。

**实施边界：** 用户已通过 `$implement 开始实施` 授权本地代码实施、隔离验证与当前分支中文提交。按本轮固定累计范围兼容，遵守长期约定与排除项，保护实际基线及独立任务成果；不创建工作树、不操作生产、不推送或发布。

- [x] 批量重启／删除从分步确认到后台结果和已确认失败项重试完整接入 04 的跟踪、取消、去重和未知结果约定。
- [x] 重启保留暂停规则的暂停状态和原统计，只处理当前存在且允许操作的项目，不恢复已删除规则或绕过权限。
- [x] 重启普通及 SNI 规则后按实际运行证据确认，保留完整分流配置、共享监听和规则限制，进度不冒充部署成功。
- [x] 删除按既有事务和费用收尾执行，正确释放相应库存／配额占用与引用、失效展示缓存，不误删同端口其他 SNI 逻辑规则。
- [x] 排队后资源删除、撤权、会话失效或并发修改时结果准确，已成功和未知项目不被自动再次删除或重启。
- [x] 通过现有管理接口、账务查询及 Agent 期望状态验证暂停项、混合规则、并发删除、取消和隔离；每种操作均可独立演示与验收。
