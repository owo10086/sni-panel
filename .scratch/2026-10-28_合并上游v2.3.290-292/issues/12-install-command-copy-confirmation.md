# 12: 复制已绑定 Token 安装命令前重新确认接管

**What to build:** 管理员每次复制安装命令时看到当前绑定主机与接管影响，可在剪贴板写入前取消误操作。

**Blocked by:** 11：同 Token 接管、旧 Agent 迁移与当前运行确认。

**Status:** completed（本地实施与隔离验收完成，未发布）

**依据：** [本轮规格](../spec.md)，用户故事 57；实施决定 28。

**实施边界：** 用户已通过 `$implement 开始实施` 授权本地代码实施、隔离验证与当前分支中文提交。按本轮固定累计范围兼容，遵守长期约定与排除项，保护实际基线及独立任务成果；不创建工作树、不操作生产、不推送或发布。

- [x] 每次复制均重新查询当前用户有权使用的 Token 及绑定状态，不只复用打开弹窗时的缓存。
- [x] 已绑定时展示主机名称、在线状态和新安装将接管的影响；取消不写剪贴板，确认后才复制，未绑定时保持正常复制。
- [x] 安装弹窗打开后发生绑定变化，本次复制显示新的实际绑定；无权访问、查询失败或状态无法确认时不绕过确认复制过期命令。
- [x] 保留 sni-panel 安装来源和既有命令功能；复制本身不执行安装、换机或升级。
- [x] 通过 Token 管理接口与浏览器剪贴板交互验证未绑定、已绑定、在线／离线、取消／确认、打开后变化、查询失败及跨账号拒绝，中英文可读。
