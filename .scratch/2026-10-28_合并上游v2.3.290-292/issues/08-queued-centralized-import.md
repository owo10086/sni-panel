# 08: 集中导入接入后台队列并统一取消与进度

**What to build:** 批量导入在后台继续执行，同时保持原有整批保存、原始行号、逐项结果和集中下发，取消与显示进度准确反映事务结果。

**Blocked by:** 04：后台批量启停与任务跟踪闭环；07：扩展端口导入与 TXT 导出重导入。

**Status:** completed（本地实施与隔离验收完成，未发布）

**依据：** [本轮规格](../spec.md)，用户故事 15、16、17、18、19、20、21、22、23、53、54；实施决定 7、8。

**实施边界：** 用户已通过 `$implement 开始实施` 授权本地代码实施、隔离验证与当前分支中文提交。按本轮固定累计范围兼容，遵守长期约定与排除项，保护实际基线及独立任务成果；不创建工作树、不操作生产、不推送或发布。

- [x] 一个既有集中导入请求仍是一个保存单元，最多 500 条；普通、SNI 及混合内容不退回逐条创建，不为适配队列静默拆批。
- [x] 停止仅取消未开始的保存单元；已启动批次按原事务完成或回滚，不能因取消留下改变原语义的半批，不撤销已提交成果。
- [x] 按逻辑输入行显示数量及原始索引／行号，区分准备中、保存中、已提交成功和运行确认；准备成功不计为已提交或已部署。
- [x] 有准备成功项后发生公共回滚时，清除暂计成功，保留确定的逐项错误，其余准确标为未保存；各类最终逐项结果合计等于输入总数。
- [x] 逐项保存点隔离、混合行竞争顺序、集中配置整理与提交后合并下发保持 ADR-0005，失败不重复占额、计费或下发。
- [x] 沿用 04 的有限去重、响应丢失查询、未知时核对、权限检查和跨用户隔离，队列容量不得放宽导入保存限制。
- [x] 通过真实测试数据库、管理接口、网页进度及 Agent 期望状态覆盖启动前取消、执行中取消、逐项失败、准备后公共回滚、500 条边界、响应丢失和未知提交结果。


**实施与验证记录：** 已落地的功能、测试入口、真实数据库／浏览器／网络证据及环境限制，统一见[正式规格中的本轮实施与验收记录](../spec.md#本轮实施与验收记录)。勾选按实际验证范围更新；不将默认跳过或生产未部署记为自动通过。
