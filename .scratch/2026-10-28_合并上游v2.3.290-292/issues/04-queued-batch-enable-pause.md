# 04: 后台批量启停与任务跟踪闭环

**What to build:** 用户从分类下拉和分步弹窗发起批量启用／暂停，服务端后台完成任务，切页后仍能查看进度、停止剩余项并核对未知结果。

**Blocked by:** None（实施授权已获得）。

**Status:** completed（本地实施与隔离验收完成，未发布）

**依据：** [本轮规格](../spec.md)，用户故事 8、9、11、19、20、21、22、23、54；实施决定 6、8、10。

**实施边界：** 用户已通过 `$implement 开始实施` 授权本地代码实施、隔离验证与当前分支中文提交。按本轮固定累计范围兼容，遵守长期约定与排除项，保护实际基线及独立任务成果；不创建工作树、不操作生产、不推送或发布。

- [x] 以批量启用／暂停贯通选择、确认、授权入队、实际执行、数量／百分比、逐项结果和通知；切换页面后继续执行并可查看。
- [x] 内存队列的任务数量、载荷和排队容量有界；停止只取消尚未开始的项目，已完成操作不撤销。
- [x] 同用户、同请求标识和同载荷在当前实例保留记录期间去重；同标识不同载荷拒绝，不承诺跨重启或永久恰好执行一次。
- [x] 入队响应丢失仅查原标识；查询失败、记录过期、实例变化或写入结果未知时提示先核对规则，不自动另建任务或重放，也不虚报成功／失败。
- [x] 按面板及用户隔离任务与同标签页恢复线索；切换账号不泄露前账号结果；排队不替代执行时对当前会话、角色、归属用户和资源权限的检查。
- [x] 已成功项和未知项不进入失败重试；仅对已确认失败项目提供重试，数量与终态一致，入队／保存成功不冒充运行生效。
- [x] 沿用主列表全选本页、换页／筛选清空及实际基线已有每页条数选择；不新增普通批量弹窗分页勾选。SNI 启停、共享监听、额度和运行确认不回退。
- [x] 通过带账号的管理接口及网页交互验证整个闭环，覆盖切页、取消、响应丢失、未知结果、重复提交、撤权和跨用户拒绝；共用能力随本单启停行为落地，不另设纯框架工单。


**实施与验证记录：** 已落地的功能、测试入口、真实数据库／浏览器／网络证据及环境限制，统一见[正式规格中的本轮实施与验收记录](../spec.md#本轮实施与验收记录)。勾选按实际验证范围更新；不将默认跳过或生产未部署记为自动通过。
