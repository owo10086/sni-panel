# 06 — 转发组与 SNI 分流规则共用端口

> 本工单已作废；端口占用相关实现以 `.scratch/port-occupancy-rework/spec.md` 和其下的新工单为准。

**What to build:** 创建转发组上的转发规则时，面板检查涉及的各入口主机。用户态绑定冲突阻止创建，内核转发的占用需要确认；已有多条 SNI 分流规则仍能共用同一个入口端口。

**Blocked by:** 05 — 用户态转发绑定冲突与同一监听复用

**Status:** wontfix

- [ ] 对转发组的全部实际入口主机分别检查端口占用，错误或警告能指出受影响的主机，普通用户看不到主机进程名
- [ ] 内核转发在任一入口主机存在不可复用的监听时要求显式确认，普通用户与管理员均可确认；用户态绑定冲突则阻止创建
- [ ] 同一入口端口上的不同 SNI 域名仍可并存，创建后续 SNI 分流规则不会把同一受管监听误判为新的绑定冲突，遵守 ADR-0002
- [ ] 转发组中任一主机缺少可靠快照时，相关结果注明主机端口信息未经核实，仍沿用现有数据库校验结果
- [ ] 现有转发组端口与 SNI 分流测试覆盖多入口主机、混合占用状态及共用端口
