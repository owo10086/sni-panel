# 08 — 批量导入时定位端口占用

> 本工单已作废；端口占用相关实现以 `.scratch/port-occupancy-rework/spec.md` 和其下的新工单为准。

**What to build:** 批量导入转发规则时，每条规则沿用单条创建的端口占用判断。导入结果标明冲突所在的原始行，内核转发的占用在提交前供操作人员确认。

**Blocked by:** 06 — 转发组与 SNI 分流规则共用端口

**Status:** wontfix

- [ ] 单主机与转发组的批量导入都检查占用；用户态冲突项不创建，错误信息指出原始行号并保留现有失败项重试行为
- [ ] 内核转发的占用警告与原始行号对应，未经显式确认的冲突项不提交；普通用户也能确认，但不能看到占用进程名
- [ ] 同批次或既有 SNI 分流规则共用入口端口时，遵守原有域名约束且不把同一受管监听误判为外部占用
- [ ] 缺少可靠快照时说明主机占用信息未经核实，并保留原有数据库校验及导入行为
- [ ] 批量导入测试覆盖部分成功、失败行号、确认后的内核规则以及共用入口端口
