# 07 — 修改与启用规则时检查端口占用

> 本工单已作废；端口占用相关实现以 `.scratch/port-occupancy-rework/spec.md` 和其下的新工单为准。

**What to build:** 管理员或有权操作的普通用户修改转发规则、改变执行方式或重新启用规则时，面板沿用创建时的端口占用判断。已确认的同一警告不会因无关字段修改而重复出现，实际占用情况变化时重新提示。

**Blocked by:** 06 — 转发组与 SNI 分流规则共用端口

**Status:** wontfix

- [ ] 单主机与转发组规则修改源端口、协议、入口主机或执行方式时重新校验，用户态绑定冲突阻止提交，内核转发的占用要求显式确认
- [ ] 重新启用规则时核对当前占用，停用期间出现的冲突会阻止用户态规则启用，内核转发仍可在确认后启用
- [ ] 修改无关字段且主机、端口、协议和占用情况均未改变时，不重复要求确认原有警告；占用情况变化后重新提示
- [ ] 普通用户仍可确认内核转发警告，校验响应和保存错误均不展示占用进程名
- [ ] 规则路由测试覆盖修改、重新启用、执行方式切换及无关字段修改
