# 10 — SNI 分流使用文档

**What to build:** 一页让管理员从零配通的文档，并把三条已知限制摆到台面上，让人在投产前就知道自己接受了什么。

**Blocked by:** 06、07（录入与可观测的最终形态确定后才写，避免文档与界面对不上）

**Status:** resolved

- [x] 按文档从零走一遍能配通，不需要试错
- [x] 写明行为边界：未匹配一律断开、入口端口被分流组独占、仅 TCP、管理员专用
- [x] 包含改动何时会断线的对照表
- [x] 包含排查路径：规则建好连不上时，先比对域名是否完全一致，再看未匹配计数涨没涨——涨了是域名对不上，没涨是流量没到出口主机；配置改了没生效时，看出口主机当前生效的配置版本与上次错误原因
- [x] 三条已知限制明确写出：出口主机单点、客户端真实 IP 不保留、入口端口只对特定域名有反应这一可观测特征
- [x] 更新链路资源对照表，让 SNI 分流出现在导航里
- [x] **不把分流表写成用户可创建的资源**。管理员管理的始终是 SNI 分流规则，分流表是分流器运行时持有的派生物——这个区分在文档里一旦模糊，就会有人来问分流表在哪个页面建
