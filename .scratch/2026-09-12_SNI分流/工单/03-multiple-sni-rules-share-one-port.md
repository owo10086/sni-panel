# 03 — 同一入口端口上多条 SNI 分流规则共存

**What to build:** 管理员能在同一个入口端口上建第二条、第三条 SNI 分流规则，各自指向不同落地机，靠域名互相区分。这是本功能的核心价值所在——把「一个落地机一个端口」压成「一个端口多个落地机」。

同时守住新的不变式：域名不能重复，端口不能与普通转发规则混用，入口侧整组只产生一份配置，每条规则各自统计流量。

放开源端口唯一性的完整理由与连带后果见 ADR-0002。

**Blocked by:** 01（拒绝与探测语义已分离）、02（单条路径已打通）

**Status:** resolved

- [x] 同一入口主机同一端口上能建成多条域名互不相同的 SNI 分流规则
- [x] 同一入口主机内域名重复时创建被拒，错误信息指出与哪一条规则冲突
- [x] 某端口已有 SNI 分流规则时，无法再建监听同端口的普通转发规则
- [x] 某端口已有普通转发规则时，无法在该端口建 SNI 分流规则
- [x] 自动分配端口时，已被分流组占用的端口不会被分配出去
- [x] 入口主机对整组只得到**一个**监听与一份转发配置，不是每条规则一份
- [x] SNI 分流规则**不产生**按目标的计数链条目
- [x] 每条规则的流量各自统计，分流器在一次上报批次里携带多条规则的数值，数值与实际传输字节一致
- [x] 不同域名的连接分别到达各自的落地机，互不串扰
