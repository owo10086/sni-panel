# 02 — 通过面板 Agent 资产发布并升级修复后的分流器

**What to build:** 修复后的 `forwardx-fxp` 进入面板携带的 Agent 资产。出口主机通过常规 Agent 升级并启用面板资产优先下载后，能够安装包含 ECH 判定修复的分流器，无需手工替换二进制，也无需修改现有 SNI 分流规则。

**Blocked by:** 01 — 带 ECH 扩展的连接按可读明文 SNI 分流

**Status:** ready-for-agent

- [ ] `forwardx-fxp` 运行时版本按现有版本规则更新，变更记录中的版本信息与源码保持一致
- [ ] 发布过程生成 `amd64` 和 `arm64` 两种 `forwardx-fxp` 二进制及对应校验和
- [ ] 面板发布包包含本次构建的分流器资产，并能通过现有 Agent 资产接口提供对应版本的下载
- [ ] `FORWARDX_AGENT_PANEL_FIRST` 启用时，升级脚本优先取得面板资产；面板资产暂时不可用时，继续遵循既有备用下载行为并保留可用的旧分流器
- [ ] 常规 Agent 升级完成后，出口主机运行的分流器版本包含工单 01 的 ECH 判定修复
- [ ] 升级过程保留现有 SNI 分流规则和分流表配置，无需配置迁移
- [ ] 升级期间的连接中断范围与既有分流器重启行为一致
- [ ] 升级后的真实连接验证覆盖带 Chrome 指纹或等价 GREASE ECH ClientHello 的场景，并确认连接到达对应目标服务
- [ ] 发布前的版本校验、测试、静态检查和资产完整性检查全部通过
