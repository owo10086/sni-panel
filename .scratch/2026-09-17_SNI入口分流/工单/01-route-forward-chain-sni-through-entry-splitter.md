# 01 — 让转发链 SNI 规则经过入口分流器

**What to build:** 单条转发链 SNI 分流规则从入口开始使用 `sni-splitter`。入口分流器读取客户端握手中的域名并连接所属转发链的下一跳，出口分流器继续按域名连接落地机。现有规则在升级后统一切换到入口分流器，不保留 gost 或 nginx 入口形态。

**Blocked by:** None — can start immediately

**Status:** resolved

- [x] 每台相关入口主机在每个入口端口上只得到一个 `sni-splitter` 受管运行时，已有转发链 SNI 分流规则升级后统一使用该运行时
- [x] 两跳转发链的入口路由指向出口分流器端口，三跳以上转发链的入口路由指向紧邻的下一位启用成员
- [x] 转发方式为 iptables 或 nftables 的转发链同样生成入口分流器，不再依赖 gost 或 nginx 入口监听器
- [x] 入口分流表不携带限速、连接数上限、最大 IP 数、访问范围及来源地址限制
- [x] 入口分流器继续遵循现有分流器契约：未知域名、无 SNI、非 TLS 及读取窗口内未完成的握手均断开，命中连接的握手字节原样发送给下一目标
- [x] 出口分流器的分流表、来源地址限制、按规则限速、连接数上限和流量计量保持原有行为
- [x] 修改规则的落地机地址或端口只改变出口分流表，入口分流表中的下一跳保持不变
- [x] 入口分流器产生的流量数字不进入账单，出口分流器继续作为唯一计量来源
- [x] Agent 心跳配合临时数据库的测试覆盖两跳链、三跳以上链、内核转发及入口与出口配置差异
