# 03 — 允许多条转发链共用一个入口端口

**What to build:** 管理员可以在相同入口主机和入口端口上，为不同转发链创建域名互不相同的 SNI 分流规则。入口主机只运行一个分流器，分流表把每个域名连接到所属转发链的下一跳。

**Blocked by:** 01 — 让转发链 SNI 规则经过入口分流器

**Status:** resolved

- [x] 表单实时预检、保存校验和转发链同步均允许不同转发链的 SNI 分流规则共用同一入口主机和入口端口
- [x] 为第二条转发链创建规则时能够保存完整的模板规则和成员规则，不因第一条转发链已使用该端口而失败
- [x] 规则录入方式继续使用现有的转发链、SNI 域名和入口端口字段，不新增可写的分流入口或分流表资源
- [x] 同一入口主机和入口端口只生成一个入口分流器，其分流表包含各转发链的域名和各自下一跳
- [x] 转发链同步使用的端口共享范围与保存校验来自同一入口范围判定，避免保存成功后同步失败
- [x] 入口组中的每台主机只收到真正指向该主机的规则，不把其它入口主机的规则加入分流表
- [x] 不同入口主机的域名集合允许存在差异，差异本身不阻止保存或同步
- [x] 同一入口主机上的重复域名继续跨端口、跨转发链和跨承载资源拒绝，并指出冲突规则
- [x] 普通转发规则与 SNI 分流规则继续双向互斥使用入口端口，端口范围和套餐限制保持不变
- [x] 隧道之间及隧道与其它承载资源之间的跨资源入口端口共用继续拒绝，端口转发资源的行为保持不变
- [x] 启动时的冲突修复不会把合法的跨转发链共享规则误判为重复端口并停用
- [x] 规则接口和 Agent 心跳测试覆盖两条以上转发链共享入口端口、重复域名、普通规则冲突及入口组成员差异
