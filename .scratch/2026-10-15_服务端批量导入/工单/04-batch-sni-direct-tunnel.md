# 04：直接隧道接入 SNI 整批导入

Status: resolved

**What to build:** 管理员向现有支持 SNI 的直接隧道批量导入时，一次提交并集中保存规则与隧道映射，入口和出口按现有方式取得完整配置，页面准确显示每条结果。

**Blocked by:** 01：主备转发组 SNI 整批导入并保留逐项结果。

- [x] 有效直接隧道的 SNI 文本和文件入口接入整批创建；仍按现有条件检查模式、单出口要求和 Agent 能力，不扩大承载支持。
- [x] 集中保存本批规则、监听引用与隧道映射，最后集中处理相关配置刷新；沿用共用权限、配额与托管含义，不引入任务记录。
- [x] 主入口及现有入口组成员沿原隧道配置取得规则，出口取得完整分流表；不能套用转发链入口分流器的配置要求。
- [x] 正确保留合法共享监听、已分配端口和映射；保存等待期间入口、出口或连接地址变化后，按现有保护重新核对。
- [x] 可定位的某条写入或映射错误仅撤回该条，其他合法项成功；最终公共保存失败则撤回本次尚未成功的新增，原有隧道和规则配置不变。
- [x] 验证失败后的映射、监听引用、端口预留与待发通知均无错误残留，后续合法保存可继续，不依赖额外同步修复。
- [x] 限额、连接数、首次和重复用量、旧规则用量与运行确认按最终分流位置保持正确；网页保留逐项结果及失败项重试。
- [x] 保存公开创建入口到入口隧道配置、出口分流表的必要检查证据，并通过直接隧道相关行为检查。
