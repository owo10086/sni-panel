# 03：转发链接入 SNI 整批导入

Status: resolved

**What to build:** 管理员向现有转发链批量导入 SNI 时，网页一次提交，后台集中保存并最后统一整理整条链，相关入口与出口取得正确分流配置，逐项失败仍可单独处理。

**Blocked by:** 01：主备转发组 SNI 整批导入并保留逐项结果。

- [x] 转发链的现有 SNI 文本和文件入口接入整批创建；混合文件的普通条目仍沿原保存方式处理并正确汇总结果。
- [x] 复用共用的权限、配额、共享端口和失败隔离能力；受影响转发链最后只整理一次，原有链路与成员身份保持稳定。
- [x] 相关入口分流表指向对应转发链的正确下一跳，出口分流表指向最终落地机；覆盖现有有效的多跳和多入口配置，不新增链路模式。
- [x] 沿用实际入口主机的域名唯一和合法跨链共享检查；相关保存或成员变化发生等待后，使用最新路线和共享资格判断。
- [x] 检查某条写入失败不留下本条派生内容，以及最终整条链保存失败完整撤回；原有规则和期望状态保留，临时预留正确释放。
- [x] 最终出口的限速、连接数与实际用量沿原方式执行和计入，不因多入口重复计量；旧规则用量与连接保持。
- [x] 只有当前配置在相关入口与出口按原约定得到确认后才显示相应运行状态；保存成功与生效分开，网页逐项结果和失败项重试正确。
- [x] 从批量创建入口直接取得相关主机配置核对本单结果，并通过转发链相关行为检查；不靠额外同步或手动切换补救。
