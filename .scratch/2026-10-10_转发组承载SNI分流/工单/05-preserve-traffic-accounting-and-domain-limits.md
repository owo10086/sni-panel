# 05：切换后继续累计用量并按域名执行限制

Status: resolved
Blocked by: 03

**当前阶段：** 已完成本地实施与验收，详见下方完成记录。

**交付内容：** 同一转发组的多个 SNI 域名各自执行限制；主备切换前后的真实流量继续归到根规则和归属用户。某个域名达量、到期或被停用时，仅撤掉该域名，其他共享端口业务继续运行。

**前置工单：** 03 — 按最新配置和实际连接完成主备切换。本单使用固定的主备成员验收，与成员增删及失败恢复的 04 单互不阻塞。

**验收条件：**

- [x] 每台成员的最终分流器按匹配到的成员规则报告实际流量，面板沿用转发组方式归到根规则及归属用户；一次连接只由实际转发它的分流器计量。
- [x] 主备切换后用量继续累计，旧入口的存活连接和新入口的新连接产生的实际流量都计入；重复报告不重复计量，也不能只计当前入口而丢掉旧入口流量。
- [x] 规则、转发组和用户现有流量展示与额度处理得到一致结果，保留现有计费及流量倍率规则。
- [x] 根规则的按域名限速、最大连接数及现有访问限制正确同步并实际执行，零值继续表示不限制；主备切换不改变保存值。
- [x] 多台成员因解析缓存或旧连接同时服务时，带宽和连接数限制按每台分流器执行，页面说明不把它们称为全组严格总上限。
- [x] 根规则额度、有效期及账户限制继续约束成员规则；切换、规则重新同步、限额恢复或重新启用都不能清零已累计用量或绕过限制。
- [x] 两个域名共用端口，其中一个达量、到期或停用时，各成员仅撤掉该域名，另一个域名的已有连接和新连接继续正常。
- [x] 保留上一份成功配置的处理不能重新放行已停用、删除、达量、到期或权限失效的域名；恢复条件满足后按已有准备流程恢复对应域名。
- [x] 通过实际流量报告处理验收根规则汇总、旧新入口报告和去重，通过心跳确认对应域名撤除；受管分流器真实连接检查验证限制及未变化域名连接保持，页面结果与用量一致。

## Answer

旧、新入口通过实际流量报告入口累计到根规则和归属用户，重复报告只计一次；提高额度、同步和启停保持累计值。限速、连接数与访问限制同步到各成员，真实 TLS 连接验证每成员连接上限及另一个域名独立使用。达量和到期后的心跳只撤掉对应域名；真实 Agent 另验证撤除更新失败时不能继续放行旧域名。带宽执行沿用原分流器，限制按成员生效，说明已写入中英文指南。
