# 03：按最新配置和实际连接完成主备切换

Status: resolved
Blocked by: 02

**当前阶段：** 已完成本地实施与验收，详见下方完成记录。

**交付内容：** 多个域名共用端口时，系统只有在某成员的所有应运行规则都使用最新配置、且能连接对应落地机时，才允许选中该成员。主入口故障后沿用现有整组切换，恢复后按原设置切回；管理员能看懂当前入口与备用入口各自的准备和健康状态。

**前置工单：** 02 — 共用入口端口并隔离单域名变更。

**验收条件：**

- [x] 每条 SNI 规则的连接检查指向该成员需要连接的落地机地址和端口，沿用现有 Agent 检查及报告入口，不改为检查成员自己的分流端口。
- [x] 规则确认运行时，核对当前保存且允许运行的规则身份、规范化域名、目标地址和端口、限速及连接数等限制；域名存在、历史生效版本或已下发动作不足以证明最新配置生效。
- [x] 成员所有应运行规则的最新配置均生效、Agent 能力符合要求且原有健康条件通过后，才具备新选择或切回资格；缺少域名、旧配置、版本异常或应用失败时不能被选中。
- [x] 页面和已有成员状态说明等待同步、更新失败及涉及的成员和规则；主入口正在工作而备用入口未准备好时，不把全部业务显示为不可用。
- [x] 保留成员优先顺序、故障与恢复观察时间、恢复后切回、整组健康汇总、流量排除、已配置健康检查、手动检查、切换记录和已开启通知的现有含义。
- [x] A 端口和分流配置正常但 A 连不到服务甲、B 能连接全部落地机时，现有 Agent 连接检查产生真实故障结果，按原有条件整组切到 B；恢复后分别验证允许切回和不允许切回。
- [x] 域名不变、落地机从甲改为乙，A 更新成功而 B 保留旧配置时，B 不能被选中；仅改变目标端口或限制设置同样核对。B 更新成功且满足健康条件后恢复资格。
- [x] 共享端口上其他规则变化，不误报未变化规则的生效内容失效，也不中断其连接；仍按成员承载的全部应运行规则判断整组资格。
- [x] 没有健康成员、公共目标失效或 DDNS 更新失败时沿用原有失败处理，不能把未完成的切换显示为成功；一次切换只更新组已有入口域名，业务域名保持原匹配值。
- [x] 通过已有故障调度、Agent 心跳和报告入口核对状态、观察时间及实际解析请求；隔离环境的真实连接验收覆盖 A 到落地机的故障和恢复，使用可控解析结果，避免改动生产解析或等待公共 DNS 缓存。

## Answer

已按当前保存内容确认准备状态，连接检查指向真实落地地址。真实 Agent 产生故障与恢复结果，现有调度验证观察窗口、整组切换、切回关闭与开启、DDNS 失败和无健康成员。另验证旧目标、旧限制、迟到报告和等待 DDNS 时再次保存均不能借用旧判断；旧转发链的报告方式继续通过。
