# 06：复制、导入导出并完成整套使用验收

Status: resolved
Blocked by: 04, 05

**当前阶段：** 已完成本地实施与验收，详见下方完成记录。

**交付内容：** 管理员可以用现有格式批量添加、复制、导出和重新导入转发组 SNI 规则，各入口准备、切换和用量结果与手工配置一致。中英文说明给出完整配置步骤和限制，并用这条批量操作路径串起整套主备验收。

**前置工单：** 04 — 安全地新增、停用和更换入口成员；05 — 切换后继续累计用量并按域名执行限制。最终验收同时覆盖这两类已完成行为。

**验收条件：**

- [x] 批量导入沿用现有 SNI 格式，可以选择已保存的主机型转发组，并逐项说明成功、冲突或失败原因；不新增另一套分流表管理入口。
- [x] 创建、修改、重新启用、复制和导入采用一致的域名、端口、所有启用成员能力、资源权限及归属用户检查；合法成员副本不被误报为重复域名。
- [x] 复制、导出和重新导入保留 SNI 域名、承载资源、入口端口、落地机及限制设置；重复域名仍按原唯一范围拒绝，不能静默转为普通规则。
- [x] 导入每项作为整套配置保存，失败项不留下根规则或部分成员规则，其他成功项不被撤回；直接修改成员规则、单条操作和批量操作采用相同托管保护。
- [x] 页面将当前入口、备用成员、已保存、待同步和失败原因表达清楚；SNI 开关、非 443 端口和组内转发工具提示符合规格，普通用户权限保持原规定。
- [x] 中英文使用说明及既有架构说明补充主机型转发组支持：每台成员直接分流到落地机，按成员执行限制、按根规则汇总用量；相关范围提示和历史引用与新规格一致。
- [x] 说明入口域名与业务域名的关系：业务域名可通过别名指向组维护的入口域名，分流仍匹配原业务域名；切换受 DNS 缓存影响，断开的连接需要重连，不能保证已建立连接迁移。
- [x] 通过批量导入两条共享端口规则，确认各入口提前就绪，制造主入口到某落地机的连接故障，验证整组切换、按原设置恢复、统计继续累计，以及单域名修改或删除不影响另一域名。
- [x] 串联验收备用入口旧配置、更换成员中途失败、保存成功但成员暂未生效、单域名达量或到期，以及 DDNS 更新失败；真实连接验收采用隔离服务和可控解析，不修改生产解析。
- [x] 适用的现有前后端检查、构建和受管分流器网络验收通过；原有普通转发组及其他 SNI 承载方式保持可用，记录实际验证结果及仍存在的环境限制。原生客户端工程、构建、验收和发布不纳入本轮。

## Answer

现有文本批量配置可选主机型转发组，JSON 复制、导出和重新导入保留 SNI、资源、端口、目标、限制、额度及到期信息。失败项不会留下部分配置，已成功项保持；重复域名继续拒绝，成员副本仍由根规则统一管理。中英文指南、领域说明、两份架构决定和历史范围引用已同步，完整检查与真实主备连接验收均通过。
