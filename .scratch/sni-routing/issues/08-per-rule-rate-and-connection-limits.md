# 08 — 每条 SNI 分流规则的限速与连接数上限

**What to build:** 同一个入口端口上不同的 SNI 分流规则，各自的限速和连接数上限独立生效、互不影响。管理员能按落地机而不是按整个端口限制带宽。

这两项和流量统计一样，只能由分流器按匹配到的规则执行：入口不解析 SNI，对同组全部规则的转发行为完全一致，在入口侧物理上无法区分。

**Blocked by:** 03（需要多条规则共用端口才能验证互不影响）

**Status:** resolved

- [x] 给其中一条规则设限速，只有该条规则的连接被限，同端口其它规则不受影响
- [x] 给其中一条规则设连接数上限，达到上限后只拒绝该条规则的新连接，其它规则照常
- [x] 限速与连接数上限的配置变更走热更新路径，不重启分流器
- [x] 未设限的规则不受任何隐式限制
