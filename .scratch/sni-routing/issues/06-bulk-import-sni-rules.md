# 06 — 批量导入 SNI 分流规则

**What to build:** 管理员选定一条链路资源、填一次入口端口，粘贴上百行文本，一次建好全部 SNI 分流规则，而不是逐条填写上百次表单。

行格式：

```
规则名#SNI域名#目标地址#目标端口
```

入口端口不放进每一行——整批共用同一个端口，重复上百次只会制造不一致的机会。

**Blocked by:** 03（需要多条规则共用端口的能力）

**Status:** ready-for-agent

- [ ] 粘贴上百行一次建成对应数量的 SNI 分流规则
- [ ] 某行格式错误时，错误信息指出**行号**与**具体原因**
- [ ] 本批次内域名重复在提交前就被发现，不靠逐条创建失败才暴露
- [ ] 与库中已有规则域名冲突时被拒，并指出冲突对象
- [ ] 落地机地址支持 IPv6 写法
- [ ] 导入失败的行保留在输入框供修正重试，已成功的行不重复创建
- [ ] 沿用现有批量导入的单次上限
- [ ] **端口冲突自动回退被关闭**：不会把源端口悄悄改成自动分配再重试。SNI 分流规则的端口是整组共享的，该回退会把规则踢出分流组，变成一条监听随机端口、永远收不到流量的孤儿规则
