# 09 — 隧道与端口转发链路接入分流器

**What to build:** 分流器同样可以挂在**隧道**出口和单机**端口转发**之后，而不只是转发链。这验证了 ADR-0001 的核心声称——分流器是独立角色，与链路类型无关，换掉入口到出口那一段的实现不需要重配任何分流规则。

隧道路径上有一处必须改：目前每条规则在出口主机上独占预留一个隧道出口端口，上百条 SNI 分流规则会把出口端口池耗尽。同组规则必须共用一个出口端口——这也是必然的，因为入口不解析 SNI，无法决定该把连接送进哪个出口端口。

**Blocked by:** 03（同组规则共用出口端口需要分流组概念）

**Status:** resolved

- [x] SNI 分流规则能挂在隧道出口之后，流量按域名到达各自落地机
- [x] SNI 分流规则能挂在单机端口转发之后，行为一致
- [x] 同组 SNI 分流规则在隧道上**共用一个出口端口**，不逐条预留
- [x] 上百条同组规则不会耗尽出口主机的隧道端口池
- [x] 切换入口到出口那一段的链路类型后，分流规则无需任何改动即可继续工作
- [x] 普通规则的隧道出口端口预留行为不受影响

## Comments

**2026-09-12** — 实现于 `f36f278`。生产环境当前正是用**端口转发**承载分流器（分流器直接监听入口 443），此前也验证过转发链承载，两种形态的 SNI 规则字段完全一致。
