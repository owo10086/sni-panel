# 09 — 隧道与端口转发链路接入分流器

**What to build:** 分流器同样可以挂在**隧道**出口和单机**端口转发**之后，而不只是转发链。这验证了 ADR-0001 的核心声称——分流器是独立角色，与链路类型无关，换掉入口到出口那一段的实现不需要重配任何分流规则。

隧道路径上有一处必须改：目前每条规则在出口主机上独占预留一个隧道出口端口，上百条 SNI 分流规则会把出口端口池耗尽。同组规则必须共用一个出口端口——这也是必然的，因为入口不解析 SNI，无法决定该把连接送进哪个出口端口。

**Blocked by:** 03（同组规则共用出口端口需要分流组概念）

**Status:** ready-for-agent

- [ ] SNI 分流规则能挂在隧道出口之后，流量按域名到达各自落地机
- [ ] SNI 分流规则能挂在单机端口转发之后，行为一致
- [ ] 同组 SNI 分流规则在隧道上**共用一个出口端口**，不逐条预留
- [ ] 上百条同组规则不会耗尽出口主机的隧道端口池
- [ ] 切换入口到出口那一段的链路类型后，分流规则无需任何改动即可继续工作
- [ ] 普通规则的隧道出口端口预留行为不受影响
