# 07 — 生效状态、未匹配计数与域名检索

**What to build:** 管理员能判断一条 SNI 分流规则到底生效了没有，能在上百条同端口规则里找到目标，能区分「客户端域名写错了」和「流量根本没到出口主机」。

单条规则的「运行中」不能沿用「端口已监听」——那对同一端口上的全部规则永远是同一个答案，等于没有状态。

**Blocked by:** 04（「当前生效配置版本」这个概念由热更新带出）

**Status:** ready-for-agent

- [ ] 单条 SNI 分流规则的「运行中」判定为：该域名已出现在出口主机**当前生效的配置版本**里
- [ ] 新建一条规则后，从「已启用但未生效」过渡到「运行中」的过程在界面上可见
- [ ] 客户端用错域名时未匹配连接计数增长；流量根本没到出口主机时该计数不变
- [ ] 配置下发校验失败时，界面能看到失败原因，并明确标注正在生效的仍是上一版本、业务未受影响
- [ ] 规则列表有域名列，支持按域名搜索，上百条规则下能直接定位
- [ ] 同一入口端口上的 SNI 分流规则在列表中归组展示，不淹没页面上其它类型的规则
- [ ] 出口主机离线时，在该组上明确提示整组落地机不可达，而不是让管理员逐条排查
- [ ] 普通转发规则的列表与表单体验不因这些改动而退步
