# 05 — 分流器端口的来源限制

**What to build:** 分流器监听端口只接受来自链路上游主机的连接，由面板自动维护，管理员不需要手工碰防火墙。

这不是可选加固。入口到出口那一段若是内核 NAT 一类的纯 L3/L4 搬运，不携带任何身份，分流器无法区分「上游转来的连接」和「外部直接连上来的连接」。若落地机把出口主机地址加入了信任白名单（常见做法），未设防的分流器端口等于把全部落地机暴露在一个被信任的位置上——而「未知域名一律断开」在这里帮不上忙，因为攻击者用的是真实存在的域名。

**Blocked by:** 02（分流器已部署并监听）

**Status:** resolved

- [x] 从链路上游主机能正常连通分流器端口
- [x] 从其它任意地址连该端口，在 TCP 握手阶段即失败，探测不到任何信息
- [x] 上游主机地址变更后来源限制自动跟随，期间不需要人工介入
- [x] 上游引用了入口组时，来源限制覆盖全部成员地址，不会出现部分客户端能连、部分不能
- [x] 来源限制随分流器配置一起下发，反复下发不累积重复条目
- [x] 分流器停用或删除时，来源限制一并清理不残留
