## 完成标准

- [x] 只改名称、排序或重复同步时，仍有效的主规则归属及修改时间不被无故重写；真正移除旧主机后迁给真实存在的候选，活动成员编号不指向已移除成员。
- [x] 历史空组没有可接替主机时，原主规则、用量和旧主机引用保留，预览显示有权查看的引用并拒绝删除；不采用上游删除主机后留下有效规则悬空编号的做法。
- [x] 成员编号未变但实际主机或隧道入口改变时，旧副本被正确识别；覆盖普通组、SNI 主机组、转发链和引用入口组的转发链，不按共用 443 判定其他域名无效。
- [x] 停用组、停用入口组、全部主规则停用及单成员禁用分别检查；真正过期副本被整理，仍保留的有效成员引用继续保护主机，不把停用混同移除。
- [x] 成员、主规则归属和必要副本一起保存，保存失败一起恢复；保存后才结算和通知，不在保存过程中等待计费而造成互相等待。配置已保存但收尾失败时明确报告。
- [x] 已待删除副本不反复被标成运行；已确认停止不重新等待。同时，第一次结算或通知失败后仍能继续未完成的收尾，已完成费用不重复扣取。
- [x] 只修正已待删除主规则的错误运行标记。真实运行过的成员副本继续等待停止确认，不能因主规则本身没有监听而提前放行。
- [x] 删除主机及 Token 前重新核对最新权限、真实引用和全部关联主机；在线等待、离线明确确认、重新上线、检查后新增引用和保存失败恢复均保留，不向普通用户泄露他人资源名称或编号。
- [x] SNI 仍按入口在线、完整当前分流配置实际生效、已开启的国内检测和观察时间选择。部分或全部落地检测缺失、过期、单落地失败均不单独卡入口或 DDNS；混合组普通规则仍执行原检测。
- [x] 以真实分流连接验证新增、撤除一个域名时其他域名监听和连接保留；只有最后用途撤除才清整个监听，撤销失败按现有安全处理拒绝旧域名并清除危险恢复资料。
- [x] 换成员、重复上报和失败重试不清零根规则、用户累计用量或额度，不重复计费；根规则先被清掉但真实副本仍待撤除时，其他域名的清理与限制不被绕过。
- [x] 接入并运行本单的主规则归属、成员释放、完整性、删除和受影响 SNI 检查，保留失败恢复及真实连接证据；不把测试留到 14 才执行。
