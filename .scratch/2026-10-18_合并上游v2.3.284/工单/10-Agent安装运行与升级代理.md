## 完成标准

- [x] 支持明确配置的 HTTP／HTTPS／SOCKS 及认证，SOCKS 域名交代理解析；无配置默认直连，空配置不继承宿主 HTTP_PROXY／ALL_PROXY 等系统代理。
- [x] 代理只覆盖注册、心跳、流量上报、事件长连接和安装升级下载；业务转发、隧道、主机公网 IP 发现、Ping／TCP／iperf 等探测保持原路径。
- [x] 代理格式错误或失效时明确失败，不自动回退直连、不静默报告安装或升级成功；凭据不出现在普通状态、错误、公开日志或诊断资料。
- [x] 面板生成的安装脚本、独立入口及升级下载继续使用本地仓库和资产，保留版本、安装目录、面板地址、Token 及原有参数。

- [x] 入口脚本下载和后续下载分别按约定设置代理，不能只让后半段有代理；系统包管理器及 SOCKS 支持不足的边界在说明和反馈中准确呈现。
- [x] 修改代理后 Agent 重启沿用现有进程身份和重新确认；重启前旧报告、迟到回复或仅在线不能认定 SNI 当前完整配置已生效。

- [x] 代理断开时管理通信如实失败，既有业务不因管理配置错误被清空；恢复后按当前完整配置确认，不把旧心跳拼成新的生效记录。
- [ ] 通过真实隔离代理验证注册、心跳、事件、上报和下载去向，以及业务／探测未代理；新旧 Agent 分开记录实际身份，旧 Agent 不因同版本被认定支持新字段。
