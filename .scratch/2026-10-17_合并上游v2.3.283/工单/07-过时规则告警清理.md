# 07: 过时规则告警不再发送

Status: ready-for-agent
Type: task
Blocked by: None

**交付结果：** 规则已经恢复、停用或删除后，不再发送排队中的旧失败告警；仍有效的异常按当前权限和通知配置发送。

**依据：** [已确认规格](../spec.md) R09；审查项 D07；配套[文档审查记录](../文档审查记录.md)和[上游变化清单](../上游变化清单.md)。

**实施授权：** 本次只授权开单，尚未开工。状态表示需求完整，不代表可以自动修改代码；获用户明确同意后才能实施。全体共同约定见[工单索引](../map.md)。

## 使用例子

规则先失败产生待发送通知，发送前已经恢复，用户不应再收到“规则仍异常”的旧消息；持续失败的其他规则仍能正常通知。

## 验收条件

- [ ] 告警实际发送前重新核对当前规则状态，已删除、停用、恢复或已不适用的旧错误不继续发送。
- [ ] 仍有效的失败按现有通知渠道、收件范围和权限发送，不因为过滤旧错误而吞掉其他正常告警。
- [ ] 规则归属或通知设置变化时按当前有效范围判断，保留 Telegram、Discord 等已有渠道配置和开关。
- [ ] 重复检查、延迟发送、规则不存在及通知异常得到可理解的记录，不把旧状态当作新失败再次扩散。
- [ ] 通过实际业务通知入口验证失效告警被过滤、有效告警可发送，保留已有通知检查。
- [ ] 提供状态变化到发送结果的对应证据，不以仅检查某个内部函数被调用作为交付。
