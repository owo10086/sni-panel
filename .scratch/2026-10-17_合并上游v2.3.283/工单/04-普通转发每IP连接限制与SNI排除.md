# 04: 普通转发每 IP 连接限制，排除 SNI

Status: ready-for-agent
Type: task
Blocked by: None

**交付结果：** 管理员现有的每 IP 设置能约束同一入口主机上该用户的普通 TCP 转发，设置与清理过程可见且不误重启业务；全部 SNI 形式保持当前连接数规则。

## 使用例子

同一个来源 IP 在同一用户的两个普通端口开 3 条和 2 条连接，共占上限 5；同一台主机上甲乙两个用户的 SNI 域名共用 443，不占这 5 个名额，也不互相误限。

## 验收条件

- [ ] 从用户当前实际生效的账户或套餐设置取得额度；明确零表示不限、非零旧设置会按新方式生效，限制的是每来源 IP 连接数而非允许多少个不同 IP。
- [ ] 普通 TCP 和双协议规则中的 TCP 按同用户、同入口主机共享名额；不同来源、用户或入口按上游范围分开计算。
- [ ] 落实 A 方案：单机、转发链、直接隧道、主机型转发组及成员派生配置中的全部 SNI 都排除；UDP 和上游原本排除的隧道规则也不进入新增限制。
- [ ] 两个不同用户共用 SNI 443 且额度不同，不导致整端口误限或整批同步失败；同机上的普通转发限制仍正常生效。
- [ ] 普通规则新增、移除、停用、改归属、改成 SNI、额度变化或改为不限后完整更新；最后一条适用规则移除时仍清理旧限制。
- [ ] 清理只处理本功能拥有的配置，保留其他防火墙和业务；增加端口保留仍有效的共享计数，重复同步和本机连接不重复占名额。
- [ ] 仅改变每 IP 设置时保留普通转发进程、连接和运行状态，现有隧道按需刷新；限速或总连接数也变化时不误省略必要更新。
- [ ] 根据 Agent 实际能力判断，旧程序、缺少运行条件或应用失败时明确报告未生效，保留既有转发，不能只看相同的 3.3.0 或收到请求就报成功。
- [ ] 设置页面、主机状态和使用说明准确区分普通限制、SNI 既有最大连接数与已取消的来源白名单；不恢复旧来源名单。
- [ ] 覆盖 IPv4、IPv6、阈值变化、空结果、应用中途失败、混合新旧程序和仍在运行的旧连接。
- [ ] 真实限制检查只在独立 Linux 网络环境执行，确认隔离后操作；缺条件记为未覆盖，不修改宿主或生产防火墙。
- [ ] 提供实际连接数、限制更新、SNI 排除和失败处理证据，记录验证所用代码、Agent 文件身份及环境。
