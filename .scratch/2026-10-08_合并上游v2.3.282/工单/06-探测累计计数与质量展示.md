## 验收条件

- [x] Agent 报告包含进程周期身份、累计总次数、成功数及批次信息，面板按单调快照差分持久累计。
- [x] 重复、乱序、旧周期及重启后的报告不重复累计；逐跳健康缓存不额外转化为新的失败次数。
- [x] 页面区分 Ping 丢包、TCP 连接失败和逐跳失败，展示的累计次数、失败率和稳定性与有效报告一致。
- [x] 旧抽样记录继续展示延迟，不参与精确失败率和稳定性评分；缺少新累计计数时明确显示准确统计暂不可用。
- [x] 旧本地 Agent 3.2.0 按实际能力处理，新增计数的门槛使用本地真正支持的版本或既有能力信息。
- [x] 显示平滑、图表聚合及多主机汇总不改变原始计数和稳定性算法，不截断原始探测次数。
- [x] 有界报告与历史查询的裁剪单位和覆盖声明一致，缺失数据不被解释为成功或已验证正常。
- [x] 升级结构与唯一性保护兼容已有 SQLite、MySQL 和 PostgreSQL 数据；通过报告去重、周期变化、持久统计和图表行为验证完整链路。
- [x] 中文与 English 的统计标签和旧数据提示表达同一口径，记录实际验证环境及未覆盖数据库。
