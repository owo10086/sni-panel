# 02: 单规则限制、用量展示与统计重置

Status: resolved

**What to build（交付结果）:** 管理员为普通规则设置限速、流量额度、计量方式和有效期，页面展示实际用量与暂停原因；达量或到期后停止转发，调整限制后按原配置恢复，统计重置清楚说明其对规则额度的影响。

**Blocked by:** 01：规则归属、目标用户配额与托管权限统一

## 验收条件

- [x] 管理员本人及其他用户的规则均支持限速、流量额度、出向／双向合计／两方向累计值取最大值等计量方式和独立有效期；默认收起配置，零或空值按上游关闭对应限制。
- [x] 普通非 SNI 规则在入口执行限速，多入口按每台入口独立执行；能力检查按实际执行限制的主机判断。
- [x] 到期或达量暂停逻辑规则及相关端点，页面展示原因；保存的启用开关、资源与端口不被改写为用户停用。
- [x] 提高额度、延长有效期或清除相应限制后，在账号、套餐、余额及其他运行条件允许时恢复；管理员身份不绕过规则运行限额。
- [x] 额度采用逻辑规则独立计数，首次使用已有累计统计建立基线；报告在已鉴权、去重的计费事务内累计，切换链路、替换成员、修改日期和普通启停不清零。
- [x] 管理员单条或全部重置在同一事务清统计与规则额度，随后协调运行状态；到期限制、账户套餐流量、余额及按量计费记录保持各自状态。
- [x] “全部统计”覆盖所选用户范围所有分页，忽略搜索、分类、链路和勾选；普通用户全量重置跳过不可重置规则，显式重置托管规则时拒绝。
- [x] 确认框按角色清楚说明实际影响，管理员能够知道达量暂停规则可能恢复；不增加独立额度重置按钮。
- [x] 页面展示累计、额度、剩余和计量方式，区分规则流量额度、可创建规则／端口配额与账户套餐流量，中文和 English 含义一致。
- [x] 通过真实业务路由、去重报告和持久用量验证达量、恢复、重置、升级基线及账号限制叠加行为。
