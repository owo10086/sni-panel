# 09: 完整双语界面与本地功能适配

Status: resolved

**What to build（交付结果）:** 用户可在完整中文和 English 界面间切换，偏好、日期金额和窄屏布局一致可用；本地 SNI、批量操作及计费编辑同样正确，语言变化不改变业务判断或用户内容。

**Blocked by:** None（无前置工单，可立即开始）

## 验收条件

- [x] 语言选择覆盖完整上游界面与本地新增入口；手动偏好优先，自动模式以浏览器语言为主，已有地区信息仅作兜底，不新增访客定位请求。
- [x] 日期、金额、长标签、确认框及按钮适配中文、English 与手机窄屏，主要操作不被截断或遮挡。
- [x] 本地 SNI、批量选择、编辑、复制、导入、删除、下载及品牌提示有完整可读翻译。
- [x] 批量成功、跳过和失败数量使用完整语言模板，英文不混入中文参数，不把规则数量译成 Bar 或 Article；兜底错误适配语言。
- [x] 用户名称、输入内容、原始诊断文本、内部枚举、持久化值与比较条件不因翻译而改变。
- [x] 计费资源类别使用稳定业务值或服务端原值判断；英文首次打开端口转发／转发链计费编辑时，类别、原资源及后续加载保持正确，保存仍指向原业务资源。
- [x] 语言切换不导致模块级静态标签永久保留旧语言，已打开页面的用户操作与结果提示遵循当前语言。
- [x] 通过语言选择、批量部分失败及英文首次编辑计费配置等可观察流程验证，保留中英文对照及窄屏检查证据。

## 实施起点

上游国际化及本地额外文案转换已应用。审查确认英文批量结果存在中文参数与错误规则计数翻译，且计费资源类别曾与翻译后的显示文字比较，导致英文首次编辑选错类别；这些问题在本工单修复并验证。
