# 08: 主机监控刷新、超时与失败恢复

Status: resolved

**What to build（交付结果）:** 用户查看主机监控时可以触发实时更新，页面恢复和网络重连会刷新；网络异常时保留上次有效数据，并可看到更新时间、失败原因及重试入口。

**Blocked by:** None（无前置工单，可立即开始）

## 验收条件

- [x] 进入监控、页面恢复及网络重连按上游触发刷新，支持实时报告请求并展示最后更新时间。
- [x] 每次请求有独立隔离与超时，旧请求或其他主机的结果不覆盖当前主机状态。
- [x] 临时网络失败保留上次成功数据，并显示准确错误与重试入口，不误报主机不存在。
- [x] 确认资源不存在与暂时加载失败采用各自准确反馈，恢复后页面可以继续更新。
- [x] 处理大量曲线点和历史数据时不因参数展开或超限崩溃，裁剪范围与实际覆盖保持一致。
- [x] 刷新、取消、超时、重连及旧响应案例通过实际页面或行为边界验证，确认请求与报告流转正常。
- [x] 中文、English 和移动窄屏下的更新时间、重试与失败提示可读，记录实际覆盖的请求与报告场景。
