# 12: AI 业务工具复用网页权限与校验

Status: resolved

**What to build（交付结果）:** 机器人按用户目标使用上游受控业务工具，规则、链路、授权、套餐、计费、主机和系统设置的操作与网页具有相同权限和业务结果，局部修改保留未指定的配置。

**Blocked by:** 01：规则归属、目标用户配额与托管权限统一；02：单规则限制、用量展示与统计重置

## 验收条件

- [x] 沿用已有 AI 开关和用户权限，工具覆盖上游提供的规则、链路、用户授权、套餐订阅、计费、主机及系统设置能力。
- [x] 写工具复用既有网页业务接口，执行规则托管权限、归属用户资源、账号状态、配额、端口范围及单规则限制校验。
- [x] 普通用户不能通过机器人编辑、启停、删除、排序或重置托管规则；SNI 没有权限例外，派生规则不能绕过根规则管理。
- [x] 局部更新保留未修改字段、资源配置和授权，操作后网页与机器人读取到同一业务真值。
- [x] 套餐订阅续期写入正确业务状态，不被后续权益同步覆盖；计费操作不会因工具入口产生重复副作用。
- [x] 凭据、数据库迁移、升级和任意命令不进入新增 AI 写工具，不扩展上游未提供的 SNI 创建参数。
- [x] 模型正文响应遵循超时与体积上限，错误与诊断可见且不泄露凭据或运行秘密。
- [x] 通过真实业务工具到路由、持久状态及用户可见结果验证读写行为，覆盖普通用户、管理员、托管规则与配置未指定字段。
- [x] 权限或配置在执行前变化时重新业务校验，失败准确返回供工作流处理，不擅自扩大目标或继续危险重试。

## 实施起点

上游业务工具与执行入口已应用，当前实现已有直接调用网页路由的路径。工单需要确认所有新写入口继承本轮托管权限、归属校验与限制，不能仅依靠机器人按钮可见性。
