# 10: 人机验证开关与 Google 账号流程

Status: resolved

**What to build（交付结果）:** 管理员可控制登录注册的人机验证，并在配置后启用 Google；用户能登录、注册、显式绑定或解绑 Google 并设置密码，所有账号策略继续生效。

**Blocked by:** None（无前置工单，可立即开始）

## 验收条件

- [x] 登录与注册人机验证默认开启，关闭后浏览器和服务端同步停用；密码校验、限流、邮箱验证和 2FA 保留。
- [x] 现有验证码与 2FA 有界 Map 清理的等价修复继续有效，不因吸收上游而退回无限增长行为。
- [x] Google 默认关闭且未配置时不自动启用；配置后注册、登录、显式绑定、确认解绑和新账号设置密码均可完成。
- [x] Google 流程执行现有注册开关、邮箱白名单、默认权限、账号禁用、2FA 和会话约定，不自动合并同邮箱账号。
- [x] 一次性浏览器状态、PKCE、签名、受众、nonce、超时与限频按上游生效，重复或无效回调不能重复建立绑定或登录。
- [x] 客户端密钥不返回浏览器，不写入明文审计或公开错误；新增身份字段兼容既有数据库与账号数据。
- [x] 使用真实 SQLite 与 HTTP 流程验证登录、显式绑定、禁用账号、关闭注册、2FA 及密码恢复；环境限制与实际失败分开记录。
- [x] 中文和 English 的登录、设置、绑定及错误提示清楚可读，升级保留原密码和既有账号策略。

## 实施起点

最终上游标签的人机验证开关和 Google OAuth 已应用。已有 Google 回归因隔离环境不允许本地监听而失败，该结果尚不能证明产品缺陷或流程通过；需要在可实际执行 HTTP 流程的环境完成验收。
