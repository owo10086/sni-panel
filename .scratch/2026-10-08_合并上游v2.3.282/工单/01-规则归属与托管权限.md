# 01: 规则归属、目标用户配额与托管权限统一

Status: resolved

**What to build（交付结果）:** 管理员新增、复制和导入规则时，规则归属遵循当前用户筛选，目标用户的资源与额度限制实际生效；普通用户只能查看托管规则，所有网页及业务入口执行一致的权限，保留本地 SNI 共享端口和批量操作体验。

**Blocked by:** None（无前置工单，可立即开始）

## 验收条件

- [x] “所有用户”下新增、复制和导入默认归实际管理员本人；指定用户下归该用户；编辑已有规则不因当前筛选而改变归属。
- [x] SNI 配置权限及管理员字段按实际操作人检查；资源授权、账号状态、套餐、余额、规则数量、端口配额及有效端口范围按归属用户检查。
- [x] 同一用户复用 SNI 入口端口不额外占用端口配额，新规则仍占规则数量；派生子规则不重复计数，并发创建保留现有配额预留保护。
- [x] 已保存托管标记、正数限速、正数流量额度或到期时间均触发普通用户只读；管理员代建 SNI 和升级前存量限速 SNI 同样执行。
- [x] 普通用户不能编辑、启停、删除、排序或重置托管规则；清空限制不会解除已保存的托管标记；无托管标记且无限制的自建规则保持正常权限。
- [x] 后端校验覆盖单条、批量、派生规则管理及统计重置；省略托管 ID、跨分页排序或直接调用接口不能间接改变托管规则的位置。
- [x] 普通用户新增、复制及导入时，未配置的管理员限制字段按上游方式处理，不因客户端默认发送零值而错误拒绝合法操作。
- [x] 行内选择、全选、逐项成功或失败反馈、剩余项重试及规则分类计数继续正常；分类总量按当前用户和搜索范围计算，不被所选链路或当前分页错误缩小。
- [x] 创建、修改及随机端口选择只检查数据库冲突、资源范围和 SNI 可复用性；真实主机监听占用继续通过运行警告或绑定错误反馈。
- [x] 使用真实业务路由和临时升级数据验证归属、托管权限、排序绕过及配额行为，并保存必要持久状态和逐项结果证据。
